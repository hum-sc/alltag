# Welcome to Alltag

Hello, and welcome to **Alltag** — a blog built the old-fashioned way.

No frameworks. No build pipelines with a thousand dependencies. Just plain HTML and a bit of JavaScript.

## Why Old Internet?

The web used to feel like an adventure. Every page was handcrafted. You could *view source* and learn something new. Pages loaded fast because they had to.

Alltag is an experiment in recapturing that spirit:

- Static HTML files
- Minimal CSS with classic 3D borders
- Client-side search without a backend
- GitHub Actions for automation

## What to Expect

I'll be writing about:

- Programming and software development
- Open source tools and projects
- Thoughts on technology culture

Thanks for stopping by. Feel free to browse around.
